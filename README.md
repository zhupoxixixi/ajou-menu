# Ajou Menu · 亚洲大学食堂菜单

**[打开网站 →](https://zhupoxixixi.github.io/ajou-menu/)**

电脑和手机可直接使用，无需登录、下载源码或填写 API 密钥。

## 功能

- **中韩双语**：右上角切换中文和韩文，刷新后保留语言选择。
- **自动选餐**：按韩国时间和当天公告，自动显示宿舍或教职工食堂的当前/下一餐；有 A/B 窗口时默认 A。
- **食堂与窗口**：选择宿舍食堂、教职工食堂、餐次和窗口；没有菜品的餐次不显示。
- **日期与状态**：支持本周、下周预告、日历和分享链接。休业显示“节假日不营业”，尚未公布显示“菜单尚未公布”，抓取异常与旧数据分别提示。
- **复制菜单**：复制日期、食堂、餐次、窗口和菜名；复制内容不含网页链接。
- **刷新与设置**：手动刷新已发布菜单；设置中可查看教职工食堂营业说明。
- **外观**：透明、半透明、磨砂三档效果，默认浅蓝灰背景；可切换纯白、选择本机图片或恢复默认。日期和设置弹窗固定使用磨砂。
- **手机与离线**：支持添加到主屏幕；联网打开后可离线查看已缓存菜单。

手动查看其他日期或餐次后，可在日历中点击 **回到当前餐次** 恢复自动选餐。

## 数据与更新

菜单来自 [亚洲大学官方食堂公告](https://www.ajou.ac.kr/kr/life/food.do)，每日韩国时间 **00:00（KST）** 自动抓取和翻译；实际执行可能延迟。翻译使用 Luna `max` 并经过独立复核，翻译不完整时保留上一版已发布数据。

这是非官方菜单助手，实际供餐、临时调整和休业安排以学校公告为准。

自选图片只在本机处理和保存，不上传服务器；网页不加载广告或分析脚本，翻译 API 密钥也不会进入公开页面。GitHub Pages 作为托管平台可能记录访问日志。外观、语言、背景和离线菜单会保存在当前浏览器，可通过浏览器站点数据清除。

## 开发

项目是部署到 GitHub Pages 的静态 PWA。修改静态文件后同步 `site/` 镜像；改动可离线缓存的文件时同时更新 `sw.js` 缓存版本。

```sh
python -m unittest discover -s tests -p 'test_*.py'
node --test tests/*.test.cjs
python -m scraper.sync_site
```

本地预览使用 `python -m http.server 8767 --bind 127.0.0.1 --directory site`，打开 `http://127.0.0.1:8767/?lang=cn`。

界面采用原生 HTML/CSS/JavaScript，不依赖第三方 CDN。参考来源和许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

# Ajou Menu · 亚洲大学食堂菜单

**[打开网站，直接查看菜单 →](https://zhupoxixixi.github.io/ajou-menu/)**

已部署到 GitHub Pages，电脑和手机浏览器都可以直接使用。**无需下载源码、安装程序或填写 API 密钥。**

## 如何使用

1. 点击右上角的 **中文 / 한국어** 切换语言。中文菜名下保留韩文原名，方便现场对照。
2. 选择 **宿舍食堂 / 教职工食堂**，再选择餐次和窗口。
3. 用底部左右按钮切换日期，或点击 **选择日期** 打开日历。手机上显示底部日历面板，电脑上显示弹窗。
4. 点击 **复制菜单**，可以复制当前窗口的菜单和分享链接。右上角还可以切换深浅主题。

默认进入宿舍食堂，按**韩国时间**和供餐截止时间显示当前或下一餐：早餐结束后显示午餐，午餐结束后显示晚餐，晚餐结束后显示次日第一餐。教职工食堂不供应早餐，次日默认午餐；有 A/B 窗口时优先 A。每天的供餐时间优先读取当天公告，页面显示对应时段。

次日菜单尚未公布时，仍显示次日日期并提示暂无菜单。手动选择日期、餐次或打开分享链接后，可以继续查看该菜单；点击日历中的 **回到当前餐次** 恢复自动选择。

## 菜单来源与更新

- 原始来源：[亚洲大学官方食堂公告](https://www.ajou.ac.kr/kr/life/food.do)。
- 仓库配置了每日韩国时间 **00:00（KST）** 的自动更新任务，实际执行时间可能延迟。
- 周末如已获取下周菜单，可以查看 **下周预告**。
- 每日抓取覆盖周一到周日，周末是否供餐以学校公告为准。
- 菜单获取失败、译文暂缺或显示旧数据时，页面会提供提示。

这是非官方菜单助手，实际供餐和临时调整以学校公告为准；各窗口菜单供分别选择。

中文翻译在菜单更新时通过 API 完成并缓存；网页访问不触发模型调用。
